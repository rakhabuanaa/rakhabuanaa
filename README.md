### 🧑‍💻 Tentang Saya

Halo! Saya adalah mahasiswa **Semester 7 Program Studi Teknologi Rekayasa Komputer (Teknik Komputer)** di **IPB University**. Saat ini saya sedang menjalani program magang di **BRMP SDLP** (Balai Besar Perakitan dan Modernisasi Sumber Daya Lahan Pertanian) yang sudah berlangsung sejak semester 6.

Dalam perjalanan magang ini, saya mengambil peran ganda yang saling melengkapi di berbagai proyek balai:
- 💻 **Web Developer:** Mengembangkan berbagai sistem informasi, termasuk menjadi *Full-Stack Developer* untuk sistem sertifikasi produk (LSPRO) dan manajemen data (RSNI).
- ⚙️ **Mekanik & 3D Designer IoT:** Bertanggung jawab dalam perancangan desain 3D dan struktur mekanik untuk alat-alat IoT pertanian modern (seperti *Smart Green House*) menggunakan Autodesk Fusion.

Saya sangat menikmati proses merancang alat secara fisik di satu sisi, dan mengembangkan *software* berbasis web di sisi lain.
